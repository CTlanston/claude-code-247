72-hour soak with operator L3 sign-off. This ADR is the record of that

`evidence/stage-K/L1-acceptance/M22c_SOAK_FINAL.md`) qualified the

## Consequences (when accepted)

**Positive**
- ADR-0011 bound 1 is supplanted for v2.1.0; the `v2.1.0` GA tag may
  be placed on the commit that points to this ADR.
- The compressed-1-day rc2 evidence remains historical record; the
  release-notes link points at this ADR.

**Negative**
- This ADR is single-use (one specific soak window). Re-running the
  soak after a hotfix on the v2.1.x line requires a new ADR-0012-rev1
  (or supersession).

## Path to `v2.1.0` GA

1. Operator schedules the 72h window.
2. Per 6h: `pnpm tsx scripts/soak-k-full.ts` (script enforces tick
   budget; operator captures stdout).
3. Per 6h: operator restarts daemon, captures recovery time.
4. Operator fills this ADR's tables.
5. Operator writes + signs `evidence/stage-K/L3-validate/operator-signoff.md`.
6. Operator flips this ADR Status to Accepted.
7. Operator tags `v2.1.0` from the latest v2-foundation commit.
