## Context

ADR-0011 bound 1 forbids `v2.2.0` GA without a real-clock 72h soak
**with `mesh.enabled: true`**, red-team round-3 re-execution at
24/48/72h checkpoints, and feature-flag flip-back validation. This ADR
is the record of that soak.

The compressed-1-day soak (`scripts/soak-k2-full.ts`, report at
`evidence/stage-K2/L1-acceptance/M23_AGENT_MESH_SOAK.md`) qualified
the branch for `v2.2.0-rc2`. ADR-0013 is the gate from `-rc2` to
`v2.2.0`.

## Consequences (when accepted)

**Positive**
- ADR-0011 bound 1 is supplanted for v2.2.0.
- The `v2.2.0` GA tag may be placed.
- Mesh layer becomes the default; v2.1 stays as the documented
  fallback via the `mesh.enabled` flag.

**Negative**
- Single-use; subsequent v2.2.x hotfixes need ADR-0013-rev1.
- The agent-tree dashboard view operator confirmation (workbook §3
  Stage M3 L3) lives in the soak — if the dashboard doesn't visualize
  the agent tree to operator's satisfaction, GA blocks regardless of
  numeric thresholds.

## Path to `v2.2.0` GA

1. ADR-0012 accepted + `v2.1.0` GA tagged.
2. Operator schedules the 72h v2.2 window.
3. Pre-run: set `mesh.enabled: true`.
4. Per 6h: `pnpm tsx scripts/soak-k2-full.ts`.
5. At t+24h / t+48h / t+72h: run the round-3 test, fill the table.
6. Per 6h: restart daemon, sample p95.
7. Late in window: flip `mesh.enabled` false for ≥ 1h, then back.
8. Operator fills + signs L3 doc.
9. Operator flips this ADR to Accepted.
10. Operator tags `v2.2.0`.

## Open items this ADR does NOT close

- Real RoadmapAgent → PR loop validation (the synthetic K2 mini-soak
  proved the wiring; the real loop runs in this 72h window).
- Real LlmReviewer subprocess cost — the sentinel's `claude --print`
  cost-per-review needs to be measured against the workbook's 8%
  budget threshold; the compressed soak's 100-review extrapolation is
  not authoritative.
