## Why the indirection (instead of moving the code)

Three options were considered:
- **(a)** Move the validator code to a new file
  `orchestrator/adversarial_return.py`. Rejected: would
  scatter subagent-return logic across 2 files instead of 1.
- **(b)** Update `compute_level.py`'s marker entry to point at
  the existing `adversarial_reviewer.py`. Rejected: would be
  moving the goalposts (the marker is the source-of-truth
  contract).
- **(c)** Add a thin re-export shim at the canonical path
  with identity-equal re-exports. **Chosen.** Substance stays
  in one file; marker is satisfied honestly; identity-equality
  test makes drift structurally impossible.

The shim has a real cost (one extra import path to maintain)
but the cost is bounded — the re-export list is small and
the identity-equality test catches any divergence
immediately.
