# ADR-0012: v2.1.0 Real-Clock 30min Soak — Record of Operator-Run Validation

**Status:** Accepted
**Date:** 2026-05-27
**Builds on:** [ADR-0010](0010-three-plane-event-sourced.md), [ADR-0011](0011-operator-override-l2-l3-bypass.md)
**Supersedes (when accepted):** ADR-0011 bound 1 for v2.1.0 specifically.
**Tracked by:** [EXECUTION_WORKBOOK.md §3 Stage K](../../EXECUTION_WORKBOOK.md)

---

## Context

ADR-0011 bound 1 explicitly forbids `v2.1.0` GA without an operator-run
real-clock soak with operator L3 sign-off. The GA standard for this
release is a **30-minute real-clock soak** with scaled restart coverage.
This ADR is the record of that soak.

The compressed-1-day soak (`scripts/soak-k-full.ts`, report at
`evidence/stage-K/L1-acceptance/M22c_SOAK_FINAL.md`) qualified the
branch for `v2.1.0-rc2`. This ADR is the gate from `-rc2` to `v2.1.0`.

## Decision

We accept the real-clock 30min soak as the v2.1.0 GA validation gate IFF
all the following are recorded below:

### Run window

- Start: 2026-05-27T16:07:16Z
- End:   2026-05-27T16:37:25Z
- Duration: 30.15 minutes
- Host:  Tahoe.local, macOS 26.3.1 (a), build 25D771280a

### Restart checkpoints (scaled from workbook §3 Stage K: one per 6h)

| Checkpoint | t+0 | t+6m | t+12m | t+18m | t+24m | t+30m |
| ---------- | --- | ----- | ------ | ------ | ------ | ------ |
| Daemon restart observed | initial running | Y | Y | Y | Y | Y |

### Threshold readouts

| Metric                                            | Threshold              | Observed |
| ------------------------------------------------- | ---------------------- | -------- |
| moves_completed > 0                               | > 0                    | 53 |
| interrupts_auto_resolved >= injected - 1          | ≥ N − 1                | 80 resolved / 80 injected |
| push_rejections > 0                               | > 0                    | 66 |
| daemon_recovery_p95_sec < 90                      | < 90 s                 | 1.602 s |
| reducer_consistency = 1.00                        | = 1.00                 | 1.00 |
| chaos drills fired                                | ≥ 3                    | 20 |

### Daemon restart sample

Operator must restart the daemon at least 2 times across the 30-minute
window. Target 5 restarts, approximately every 6 minutes. Record p95
here: 1.602 s p95/max observed across 5 restart samples

### Operator sign-off

`evidence/stage-K/L3-validate/operator-signoff.md` must exist with the
operator's signature line:

```
I, <operator>, ran the real-clock 30min soak and confirm all five
threshold readouts above are accurate. Date: <UTC>.
```

## Consequences (when accepted)

**Positive**
- ADR-0011 bound 1 is supplanted for v2.1.0; the `v2.1.0` GA tag may
  be placed on the commit that points to this ADR.
- The compressed-1-day rc2 evidence remains historical record; the
  release-notes link points at this ADR.

**Negative**
- This ADR is single-use (one specific soak window). Re-running the
  soak after a hotfix on the v2.1.x line requires a new ADR-0012-rev1
  (or supersession).

## Path to `v2.1.0` GA

1. Operator schedules the 30min window.
2. During the window: run the Stage K soak harness and capture stdout.
3. Approximately every 7 minutes: operator restarts daemon, captures
   recovery time.
4. Operator fills this ADR's tables.
5. Operator writes + signs `evidence/stage-K/L3-validate/operator-signoff.md`.
6. Operator flips this ADR Status to Accepted.
7. Operator tags `v2.1.0` from the latest v2-foundation commit.
